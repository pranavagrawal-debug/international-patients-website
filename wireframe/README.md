# Wireframe

Layout-only wireframes (no real content). Open `wireframe/index.html` in a browser; nav links move between pages.

- index.html: Home (desktop)
- home-mobile.html: Home (mobile)
- treatments.html, treatment-detail.html, doctors.html, plan-your-visit.html, faq.html, contact.html

`source/` holds the editable Claude design-canvas files.

## Changing the hero photo

Upload your image to `public/assets/hero.jpg` (GitHub: Add file > Upload files). It becomes the Home hero background automatically. Until then a gray gradient shows. The heading, paragraph and buttons are in the `hero` block of `wireframe/index.html`.
